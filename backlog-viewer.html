Financial Signal Dashboard

A research/signal tool, not a trading tool: it ingests price history, news, public insider filings, and social speculation, then asks Claude to produce a dated, cited signal per ticker on a schedule the user sets.

No trade execution — dashboard only BYO Claude key — per user Next.js + Node.js + Postgres US equities, 4 data sources ~10 users — friends and family, no public launch
